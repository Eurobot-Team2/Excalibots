# Eurobot 2027 — Master in Advanced Mechatronics

**PROJ 703 & PROJ 903 | International Robotics Challenge**

This repository hosts the collaborative development of an autonomous robot for the **Eurobot 2027** international robotics challenge, as part of the Master in Advanced Mechatronics at Polytech Annecy-Chambéry, Université Savoie Mont Blanc.

The project brings together robotics, artificial intelligence, and mechatronics to design, simulate, implement, and validate an autonomous robotic system capable of performing the tasks defined by the Eurobot 2027 rules.

## Project Objectives

Our goal is to develop a reliable and autonomous robotic system through collaborative engineering, iterative development, and experimental validation.

The main technical areas include:

- **ROS 2:** Robot software architecture, communication, and integration.
- **Computer Vision:** Perception, object detection, and environmental understanding.
- **Navigation:** Localization, mapping, path planning, and autonomous movement.
- **Simulation:** Robot modeling, virtual environments, and testing using Gazebo.
- **Intelligent Control:** Decision-making, task planning, and autonomous behavior.
- **Mechatronics:** Integration of mechanical, electronic, and software components.

The implementation will evolve according to the official Eurobot 2027 rules and the team's design decisions.

## Development Environment

The project uses a local development environment based on ROS 2 and Gazebo. Each team member should install the required tools and dependencies according to the project's setup documentation.

Recommended tools:

- [Visual Studio Code](https://code.visualstudio.com/)
- [ROS 2 Documentation](https://docs.ros.org/)
- [Gazebo](https://gazebosim.org/)
- [Git](https://git-scm.com/)

Installation instructions and dependency requirements will be documented as the development environment is established.

## Repository Structure

The repository is organized to support modular development and team collaboration.

- `ros2_ws/src/` — ROS 2 packages and robot software.
- `docs/` — Project documentation, requirements, and design decisions.
- `hardware/` — Mechanical and electronic design resources.
- `experiments/` — Testing, evaluation, and experimental results.

The structure may evolve as the project progresses.

## Team Collaboration Guidelines

- Follow the agreed repository structure and coding conventions.
- Develop and test changes in dedicated branches when appropriate.
- Use clear commit messages and pull requests for collaborative changes.
- Document important design decisions, interfaces, and experiments.
- Keep simulation, perception, navigation, control, and hardware components modular.
- Avoid committing generated files, build artifacts, and local environment settings.
- Ensure that all team members contribute to development, testing, and documentation.

## Official Challenge

Follow the [official Eurobot website](https://www.eurobot.org/) for competition information, rules, and updates.

The robot's strategy, perception systems, navigation, and control logic will be designed around the official **Eurobot 2027** challenge requirements.
