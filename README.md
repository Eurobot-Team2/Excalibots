# Eurobot 2027 — Master in Advanced Mechatronics

**PROJ 703 & PROJ 903 | International Robotics Challenge**

This repository hosts the collaborative development of an autonomous robot for the **Eurobot 2027** international robotics challenge as part of the Master in Advanced Mechatronics at Polytech Annecy-Chambéry and Université Savoie Mont Blanc.

The project combines robotics and mechatronics to design, simulate, implement and validate an autonomous robotic system capable of performing the tasks defined by the official Eurobot 2027 rules.

  <strong>⚙️ Design · Simulate · Develop · Test · Compete ⚙️</strong>
</p>

## Project Objectives

Our goal is to develop a reliable and autonomous robotic system through collaborative engineering and iterative testing.

The main technical areas include:

- **ROS 2:** Robot software architecture and communication.
- **Computer Vision:** Object detection and environmental perception.
- **Navigation:** Localization, mapping, path planning and autonomous movement.
- **Simulation:** Robot modeling and virtual testing using Gazebo.
- **Intelligent Control:** Decision-making, task planning and autonomous behavior.
- **Mechatronics:** Integration of mechanical, electronic and software components.

## Selected Team Strategy

Following our analysis of the Eurobot 2027 challenge, our team has selected **Action 1 and Action 3** as the primary strategic actions guiding our robot's development.

Our implementation will focus on developing the required mechanical systems, perception capabilities and autonomous behaviors to perform these actions reliably within the competition constraints.

The detailed strategy and implementation will be refined according to the official rules and our experimental results.

## Development Environment

The project uses a local development environment based on ROS 2 and Gazebo. Each team member is responsible for installing the required tools and dependencies according to the project documentation.

Recommended tools:

- [Visual Studio Code](https://code.visualstudio.com/)
- [ROS 2 Documentation](https://docs.ros.org/)
- [Gazebo](https://gazebosim.org/)
- [Git](https://git-scm.com/)

## Repository Structure

- `ros2_ws/src/` — ROS 2 packages and robot software.
- `docs/` — Project documentation and design decisions.
- `hardware/` — Mechanical and electronic design resources.
- `experiments/` — Testing and evaluation results.

The structure may evolve as the project progresses.

## Team Collaboration Guidelines

- Follow the agreed repository structure and coding conventions.
- Use dedicated branches for development when appropriate.
- Write clear commit messages and use pull requests for collaborative changes.
- Document important design decisions and experimental results.
- Keep perception, navigation, control and hardware components modular.
- Avoid committing generated files and local environment settings.
- Encourage contributions from all team members across development and documentation.

## Official Challenge

Visit the [official Eurobot website](https://www.eurobot.org/) for competition information and rule updates.

All robot design decisions and implementation priorities will be aligned with the official Eurobot 2027 requirements.
